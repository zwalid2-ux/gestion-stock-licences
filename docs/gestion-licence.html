🔑 Licences hébergées sur GitHub

Le serveur installé sur un poste n'est plus nécessaire pour administrer les licences. Utilisez un jeton GitHub limité à ce dépôt (Contents : lecture/écriture), puis sélectionnez la clé de signature d'origine.

La base client est chiffrée avant publication ; les codes signés ne contiennent ni nom ni téléphone. Sauvegardez la clé hors de GitHub et importez-la sur tout autre appareil administrateur autorisé.

Demande d'un poste hors ligne : Copiez l'identité du poste depuis la page Licence STOKY, puis transmettez-la à l'administrateur.
