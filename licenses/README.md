# Licences GestionStock

Chaque fichier `licenses/<CODE-MACHINE>.lic` contient une licence signée (ECDSA P-256).
Le fichier est publié par l'outil d'administration `LicenceAdmin` et récupéré par l'application via raw.githubusercontent.com.

La falsification est impossible sans la clé privée : l'application vérifie la signature avec la clé publique embarquée.
